## What to update when you change something

| You changed… | Update |
|---|---|
| Anything (every PR) | One entry in **CHANGELOG.md** (date, PR, migration, what users see) |
| A database migration | CHANGELOG "Next Flyway migration" + HANDOVER rule 3 (next number) |
| Behaviour users see (screens, rules, messages) | **User guides** EN + TA and regenerate the help HTML; the data-entry guides if fields changed |
| A rule, permission or tenant / branch check | HANDOVER (short note) + ACCESS_CONTROL.md |
| A whole new feature / module | HANDOVER section (what, where in code, migration) and, if large, its own `docs/<FEATURE>.md` listed above |
| Reports | `tools/reports/generate_catalog.py` (source) → regenerate the catalog; REPORTS.md if the hub changed |
| Deployment / environment | HANDOVER "Deploy" section |
